# ChatGPT 🔥本気で聞くボタン N1.1.0

ChatGPTの推論レベルを送信内容に応じて自動で切り替えるTampermonkey用ユーザースクリプトです。

## N1.1.0の変更

- 添付ファイル付きの通常送信を自動判定
- 通常Chat：添付ありの場合は「最速」で送信
- Work：添付ありの場合は「軽量」で送信
- 回答完了後、送信前の推論レベルへ自動復元
- 送信ボタンのクリックとEnter送信に対応
- 「🔥 本気で聞く」は従来どおり最上位設定を優先

## 優先順位

1. 「🔥 本気で聞く」から送信 → 最大優先
2. 通常送信で添付あり → 通常Chatは最速、Workは軽量
3. 添付なしの通常送信 → ChatGPT側の現在設定のまま

## 添付判定

入力欄（composer）内にある、ファイル名を `aria-label` に持つ添付ボタンを検出します。

例：

```html
<button aria-label="log(2).txt">
```

一般的な文書、ログ、画像、動画、音声、圧縮ファイル、ソースコードの拡張子に対応しています。

## インストール

1. ブラウザへTampermonkeyを導入
2. `chatgpt-honki-button-N1.1.0.user.js` を開く
3. Tampermonkeyのインストール画面で登録
4. ChatGPTのタブを再読み込みする

古い版が有効なままだと二重動作する可能性があるため、N1.0.0以前は無効化してください。

## 対象

- `https://chatgpt.com/*`
- 通常Chat
- Work UI

## 注意事項

- 現在は日本語版ChatGPTを主対象にしています。
- ChatGPT側の画面構造や表示名が変わると動作しなくなる可能性があります。
