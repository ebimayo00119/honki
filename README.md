# 🔥 ChatGPT 本気で聞く

ChatGPTの思考レベルを、質問の内容に応じて自動で切り替えるTampermonkey用ツールです。

## 主な機能

* 通常時は「中程度」または「高い」で利用
* ファイルや画像の添付送信時は軽量化
* 「🔥本気で聞く」ボタンを押すと、その質問だけ利用可能な最上位設定で送信
* 回答完了後は、元の思考レベルへ自動で戻る
* 通常のChatGPTとWorkの両方に対応

「最大」などの重い思考レベルを常用せず、必要な質問だけ本気で考えてもらうためのツールです。

## インストール方法

1. ブラウザにTampermonkeyをインストールします。
2. このページにあるZIPファイルをダウンロードして展開します。
3. ZIP内の `.user.js` ファイルを開きます。
4. Tampermonkeyの画面で「インストール」を押します。
5. ChatGPTのページを再読み込みします。

入力欄の近くに「🔥本気で聞く」ボタンが表示されれば完了です。

## 使い方

普段は「中程度」または「高い」で、通常どおり送信してください。

難しい質問や、より深く考えてほしい質問では「🔥本気で聞く」ボタンを押します。その質問だけ思考レベルを引き上げて送信し、回答後は元の設定へ戻ります。

ファイルや画像を添付して送信した場合は、自動的に軽い思考レベルへ切り替えます。

## 海外で利用する方へ

ボタン名は日本語で「🔥本気で聞く」と表示されます。

海外で利用する場合や、別の表示名にしたい場合は、スクリプト内のボタン名を好きな言語・名称へ変更してください。

## 注意事項

* 「最大」「非常に高い」などには利用制限が設定される場合があります。
* 利用できる思考レベルは、契約プランやChatGPTの環境によって異なります。
* ChatGPTの画面仕様やバージョン変更により、動作しなくなる場合があります。
